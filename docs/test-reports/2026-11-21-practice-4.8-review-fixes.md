## Notes for reviewers

- `V202611150001__init_classroom_practice.sql` was edited in place (new columns, tighter limits) because it is not on `main` yet. A database that already applied the earlier version of this file fails Flyway validation (checksum); recreate it or run `flyway repair`.
- `ON CONFLICT DO NOTHING` is used without a conflict target: it is valid PostgreSQL and the only form H2's PostgreSQL mode parses. The table has a single unique key (the primary key), so the behaviour is identical.
- `LessonStatusPort` gained `archivedLessonIds(classroomId)`; module 4.5's adapter must implement it. `PracticeJudgePort.SubmitResult` gained `testsPassed`; the 4.9 adapter must supply it (0..number of testcases, equal to it when ACCEPTED).
- Admin access (open question): practice endpoints still answer 403 to Admin, matching FR-PRC-001..004. No code change until the team decides whether FR-CLS-001 / FR-GRD-001 imply Admin read access to practice data in the MVP.
